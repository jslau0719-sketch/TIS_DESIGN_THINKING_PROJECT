# Design Thinking - Low Fidelity Prototype

## Overview 
This project is aims to brainstorm and develop a low fidelity prototype - expense tracking application.

## Summary
The design thinking process was conducted in 5 phases:
- Empathy: Understanding students’ spending behavior through observation and questionnaire
- Define: Identifying the main issue that lead to student overspending
- Ideate: Brainstorming features needed for an expense tracking application to deal with problem identified in define phase
- Prototype: Developing a low fidelity prototype using Figma
- Test and Deployment: Evaluating the prototype based on users feedback
